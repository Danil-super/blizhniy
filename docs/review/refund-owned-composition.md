## Изменение поведения

Обработчик возвратов получает отдельный вход для физически проверенного
локального контейнера. Используется уже согласованная проверка owned state,
Docker definition/live binding и фактических байтов CA того же Pool config.
Обычные фабрики по-прежнему допускают только `blizhniy_test`. Выбор нового
профиля не управляется переменной окружения: его передаёт только отдельная
фабрика после проверки контейнера/сертификата.

Прежняя schema55 описывала только миграции. На ручном стенде дополнительно
есть две телефонные RLS policy и три внешних FK симулятора оплаты, создающие
шесть RI-триггеров в app. Их удаление сломало бы существующий стенд.
Добавлен отдельный literal fingerprint только для этой локальной schema55.
Обычные schema54/55 fingerprints не изменены и не принимают локальный профиль.
Оба verifier сохраняют точные identity/ACL/journal/TEST-проверки; localPrimary
разрешён только для `blizhniy_prod` и полной schema55.

Сверка теперь учитывает полные policy: роли по именам вместо нестабильных OID,
команду, permissive/restrictive, USING и WITH CHECK. Внешние FK учитываются
вместе с определениями и состоянием ограничений; их RI-триггеры уже входили
в прежний fingerprint. Неизвестные policy/FK/триггеры по-прежнему отклоняются.

DDL двух таблиц симулятора перенесён без изменения колонок и ограничений
в `database/local-primary-payment.sql`; симулятор создаёт обе вместе.
Это общий источник для локальной оплаты и воспроизводимого профиля.
Он не входит в production-миграции. Builder включает новый fingerprint
в operator/schema55-worker, а schema54-worker сохраняет прежнюю границу.

Также исправлено раскрытие driver error при закрытии worker: ошибка теперь
обезличена, результат close кэшируется, повтор не открывает/закрывает pool снова.

миграций и автоматического восстановления при расхождении.

Это согласование не разрешает установку ролей/миграций, запуск постоянных
служб, настоящие TEST/LIVE запросы, push/deploy или изменения production.

от их компрометации не заявляется. Настоящая TEST/fiscal приёмка остаётся
отдельным незавершённым пунктом.

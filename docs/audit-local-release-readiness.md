Комбинированный оператор собирается через `buildUserAccessOperator(destination, { hosted: 'tariffs' })`. Он требует основной журнал до 0087 с безопасной отменой 0071 и отдельный журнал 0061, 0062, 0088. В EnvironmentFile оператора тот же тарифный флаг выбирает только проверенную функцию изменения цены, срока и активности. Отключение тарифного флага у веб-приложения возвращает чтение тарифов через веб-роль. Для сохранения управления пользователями установленный комбинированный оператор продолжает работать с неизменными журналами при откате веб-приложения.

# Уведомление о cookie

Добавлено информационное уведомление с кратким описанием cookie входа/защиты аккаунта и хранения настроек в браузере. «Подробнее» открывает действующий раздел8 политики конфиденциальности по якорю /legal/privacy#cookies. Текст правовых документов не менялся. Кнопка «Понятно» фиксирует ознакомление с уведомлением; согласие с условиями регистрации и настройки аналитики этим не заменяются.

Отметка `__Host-blizhniy_cookie_notice=v1` хранится год: Secure, Path=/, SameSite=Lax, без Domain. Это доступная интерфейсу настройка без токена, номера, email, пользовательского ID и прав доступа. Cookie сессии остаётся отдельным HttpOnly cookie с прежним серверным сроком8 часов; выдача/отзыв сессий, БД и grants не изменены. Публикация новой сборки сама по себе не сбрасывает отметку ознакомления.

Уведомление можно повторно открыть кнопкой «О файлах cookie» в подвале. При этом фокус переводится на панель, после закрытия возвращается к кнопке. На мобильном панель находится над нижней навигацией. Автоматическое появление отключено в коротком окне подтверждения телефона, чтобы сохранить сценарий подтверждения и автозакрытия. Ручное открытие доступно и там.

Проверены первый визит, переходы/перезагрузка, полный перезапуск Chromium с тем же собственным профилем, повторное открытие и возврат фокуса, политика cookies, размеры320/390/768/1440 и альбомный экран740×360. При запрете доступа к document.cookie панель закрывается в текущей вкладке без ошибки; если браузер не позволяет сохранять cookie, после новой загрузки уведомление может появиться снова.

В `scripts/check-cookie-notice.mjs` используются только собственный локальный стенд, анонимный браузер и временный профиль вне проекта. Вход в аккаунт не выполняется, production данные и провайдеры не используются. Отдельно выполняется прежний сценарий подтверждения телефона. В native SSR-adapter добавлен новый клиентский компонент, который при SSR возвращает null; проверки сериализации секретов и выбора backend сохранены.

## Ошибка и результат

Отчёт аудита фиксирует Permission denied для `/zap/wrk/zap.yaml` и
`/zap/wrk/zap-report.html` в запуске43849886145. Нынешний workflow монтирует
весь checkout, принадлежащий runner, а ZAP запускается своим nonroot-пользователем.
Кандидат монтирует только отдельный каталог `$RUNNER_TEMP/zap-reports`.

Существующий шаг подготовки создаёт каталог с2770, записывает его путь в
`GITHUB_ENV`. Контейнер сохраняет стандартные пользователя и команду образа,
получая только дополнительную группу runner. Setgid сохраняет эту группу у
создаваемых файлов; runner может прочитать отчёты для summary/upload.
Checkout, ключи и остальные каталоги в контейнер не передаются.

Пути summary и трёх artifacts используют тот же `ZAP_REPORT_DIR`.
Не меняются цель сканирования, аргументы baseline,25минут job,
`if-no-files-found:error`,14дней хранения и завершающий check-zap-result.sh.
Коды1/2/3/неизвестный и отсутствие любого непустого отчёта сохраняют failure.
Правила находок не исключаются; предупреждения не превращаются в success.

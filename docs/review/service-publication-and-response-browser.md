# Браузерные проверки отклика и публикаций услуг

Пакет подготовлен для ревью по S4.1, S4.2 и S4.5. [Патч](service-publication-and-response-browser.patch) меняет два браузерных теста и добавляет в существующий механизм `check:floor` две пары SHA256 их полного содержимого. Применение пакета требует ревью владельца по `CONSTRAINTS.md`.

| Где сработал floor | Что требуется проверить |
| --- | --- |
| Отклик, строка 125 | Для нового сообщения проверяются ограничение поля 500 символами, отказ при разметке, отсутствие записи и фокус на поле. Чтение ранее отправленного сообщения до 3 000 символов отдельно проверяет `tests/client-applications.test.mjs`. |
| Услуги, строка 59 | Потеря ответа после сохранения по-прежнему оставляет ровно одну запись до чтения результата. |
| Услуги, строка 60 | После сверки открывается карточка в соответствующем кабинете. Сохраняются проверки чтения, единственной записи и правильного заголовка. Имя специалиста приходит из профиля. |
| Услуги, строка 63 | Повторное открытие подтверждает сохранённую ревизию и данные. Специалист меняет описание, а имя остаётся из профиля. Загрузка фото Ярмарки выполняется один раз. Анкета специалиста и рекламная строка сохраняются без загрузки. |
| Услуги, строки 65–66 | На ширинах 320, 768 и 1 440 пикселей сохраняются проверка горизонтального переполнения и запрет серьёзных нарушений axe. Дополнительно включены правила WCAG 2.2 AA. |
| Услуги, строки 70 и 72 | После смены аккаунта приватный текст исчезает, чужая форма недоступна и число записей остаётся прежним. После возврата владельца вновь открывается сохранённая версия без прежнего несохранённого текста. |

Сценарий отказа при модерации по-прежнему проходит до повторного открытия редактируемой карточки, проверки текста и подтверждения двух попыток сохранения. Дополнительно проверяется, что модерация использует текущую ревизию и сама по себе не оплачивает и не публикует материал.

На сборке `726098e3` штатные браузерные файлы дали 17 успешных результатов и пять непройденных сценариев. TAP также отметил два родительских набора. С тестовой частью патча прошли все 24 проверки Chromium на том же веб-архиве в изолированной локальной сети с синтетическими ответами API. В отдельной копии предложенные пары SHA256 прошли `check:floor` и 38 проверок guard и контрактов откликов. Изменение любого из двух файлов сверх точного патча снова блокировалось. Оба варианта проверки выполнены во временных копиях.

Отчёты сохранены вне Git в `audit-release-726098e3.fZMrOI85/browser/` и `audit-browser-review.b3baQNLd/`.

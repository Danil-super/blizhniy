## Откат и ограничения

Старый веб-build допустим только до DDL. После установки схемы36 сохраняется
новый совместимый reader с исправленным read-only gate независимо от числа
допущенных покупок. Старый guard не принимает журнал36: нельзя просто подменить
новый worker прежним пакетом33. Добавочные таблицы/история не удаляются.
При проблеме отключается **создание/dispatch**
новых покупок (`BLIZHNIY_LISTING_PAYMENT=disabled`), а новый совместимый reader и
worker сохраняются для сверки уже известных платежей. Их остановка допустима
как аварийная пауза, но не считается завершением этих заказов. Выпуск старого
UI, обещающего отсутствие публикации для всех TEST, после активации не является
полным функциональным откатом. Схема/история и старые финансовые статусы сохраняются.

Старый успешный verification-only TEST освобождается для редактирования, но
прежний уникальный активный заказ не позволяет повторно купить размещение
той же карточки. Для полного TEST-прогона создаются новые черновики.
Отмена с возвратом, раннее продление, платные отклики, бронирования и ярмарка
не активируются этим пакетом. LIVE — следующий отдельный выпуск.

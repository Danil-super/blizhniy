## Ошибка установщика, найденная до запуска

Инженерное review обнаружило, что отказ записи финального proof после COMMIT мог
оставить ошибочную отметку «до COMMIT» и роль LOGIN. Введён отдельный didCommit;
поздний отказ сохраняет committed-классификацию и пытается отключить только новую
роль. Неизвестный COMMIT сохраняет credential и требует read-only сверки.
Failure injection на фактическом catch source прошёл4/4: ошибка proof, недоступное
отключение роли, неизвестный COMMIT и обычный отказ до COMMIT. Review исправления
замечание закрыл. Реальная установка прошла без этой аварийной ветки.

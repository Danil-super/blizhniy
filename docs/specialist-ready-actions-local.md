# Анкета для откликов и меню карточек — локально, 25.10.2026

## Договор изменения

- Только локальный стенд. Без production, DDL/ACL и финансовых мутаций.
- В анкете одно поле «О себе» вместо навыков/опыта/описания. При открытии старой
  формы информация объединяется без молчаливого удаления или обрезки.
- Сохранённая полная анкета используется для откликов без её модерации/оплаты.
  Это не публикация в каталоге и не отмена собственного финансового состояния отклика.
- Неизменны ownership/session/verified/nonblocked, активные справочники, согласие,
  контакты, CAS и eligibility целевой вакансии/заказа.
- В списке объявлений открыто не более одного меню «Действия»; другая кнопка
  закрывает предыдущее меню. Управление публикацией/оплатой не меняется.

## Проверяемые границы

HTTP/FormData недоверенны; профильное имя читается сервером внутри owner-транзакции.
Новый trusted-policy задаётся composition, не HTTP. Анкете не назначаются
`is_paid`, `published`, период размещения или фиктивное одобрение.
Обработчики ничего не отправляют внешним сервисам. Приватные контакты не попадают
в каталог и получателю недоставленного неоплаченного отклика.

Независимый RED: `tests/specialist-application-ready.test.cjs`, 17 сценариев,
3 положительных/CAS сценария падали на прежнем требовании опубликованной анкеты.
Миграция 0018 не требует paid/published специалиста через CHECK/trigger; новая DDL не нужна.

## Реализация и проверка

Одна `description` хранит «О себе» (20–3000 символов для готовой анкеты).
Старые отдельные тексты объединяются перед очисткой устаревших полей. При
превышении лимита форма просит сократить текст, не обрезает его молча.
Полный текст попадает в snapshot отклика `about`; прежний ограниченный
`skills` сохраняется как совместимый краткий отрывок для старых откликов.
При открытии формы без ID серверная анкета того же владельца загружается
для редактирования: новая пустая анкета не подменяет существующую.

Готовность для отклика проверяется сервером отдельно от платной публикации
в каталоге: текущие профильное имя, город/активная профессия, текст, цена,
согласие и контакты. UI не вызывает модерацию анкеты. Старые default-policy
repositories и порядок модерации других типов не изменены.

Меню используют native `details` с общей группой и scoped click-capture:
другая карточка/кнопка закрывает прежнее, текущая summary работает нативно.
Escape закрывает меню и возвращает фокус на его summary. Состояние попытки
оплаты и owner actions не затронуто.

Проверки:

- Native1933/1933; floor/types/lint без ошибок, прежний warning в
  `tests/checkout-prerequisites.test.cjs` остаётся явно видимым.
- Build65/65 страниц. Graphify обновлён AST-only с прежними исключениями;
  Code Graph переиндексирован.
- Mutation: инверсия проверки готовности вызвала 8 падений из 17; исходник
  восстановлен с тем же SHA-256, focused suite снова проходит.
- Chromium на прежней сборке воспроизвёл незакрывающееся меню; на новой
  прошли мышь/Enter/Space/Escape, другая кнопка, отсутствие лишних API writes.
- `scripts/check-local-specialist-ready-ui.mjs`: настоящие cookie-session,
  сохранение/повторное открытие анкеты и создание отклика на синтетический
  опубликованный заказ под ограниченной runtime-ролью. Текст более 500
  символов сохранён полностью. У анкеты по-прежнему `draft/paid=false`,
  отклик `pending_payment/paid=false/sentAt=null`; каталог не опубликован.
- 320/768/1024/1440px без горизонтального overflow, axe serious/critical0,
  pageerror0. Скриншоты просмотрены; это не полный ручной WCAG-аудит.

Новых таблиц, прав, списаний, внешних provider calls и изменений production
нет. Оплата/доставка самого отклика этим изменением не включается.

Совместимость каталога: profile-bound публичная анкета больше не требует
устаревшего `skills`, но по-прежнему требует paid/published, действующий срок,
форму и разрешённую identity. Старые навыки/опыт включаются в публичное
описание без дублирующего блока. SQL-допуск/одобрение каталога не снимается.
Отдельный RED→GREEN проверяет отсутствие навыков с сохранением отказов
для неоплаченной/черновой/истёкшей анкеты и metadata без пустого префикса.
Уже оплаченные старые записи с раздельными текстами сохраняют прежние
по-полевые лимиты до редактирования: объединённый текст более 3000 символов
не скрывает прежнюю публичную карточку. При новом сохранении применяется
явный лимит единого «О себе», без молчаливой обрезки.

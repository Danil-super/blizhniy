# Единый формат публичных карточек

23.10.2026. Только локальный стенд https://127.0.0.1:3045/__local.
Production, SSH, рабочая БД, DDL/ACL, LIVE и платёжные правила не менялись.

## Представление

Объявление, вакансия и заказ используют общий PublicationHeading:
единственный h1, затем одна цена и метки вида/профессии/статуса.
Шапка предшествует галерее на всех ширинах. Основной контент740px и
контактная колонка340px используют прежний адаптивный grid; на узких экранах
блоки располагаются последовательно. Даты и место сопутствуют галерее.

У вакансии сохранены работодатель, график, формат, описание, обязанности,
требования, условия, отклики и скрытие приватных контактов. У объявления
сохранены категория/подкатегория, срок, контакты, share, продавец, карта,
бронирование и ограничения public eligibility. Цена больше не дублируется
в отдельных mobile/desktop панелях. Дата размещения перенесена из нижнего
описания наверх без создания второй даты из технического updated_at.

В кабинете у published/blocked/archived/expired/sold нет Подробнее и её
переименованного аналога. Для draft/pending_payment/paid остаётся Статус и
оплата — это существующий вход в незавершённое размещение. Действия,
редактор, просмотр, снятие/возврат, удаление blocked и причина сохранены.

Контраст подписей и ссылки профиля в ListingSellerCard усилен; фон кнопок
звонка/расчёта затемнён в пределах прежней зелёной палитры. У метки графика и
действий карточки усилен синий цвет текста, включая hover. Это устраняет
обнаруженный axe color-contrast без изменения самих действий.

## Доказательства

- Семь новых регрессий actual SSR/function + owner cards сначала дали7 RED,
  после реализации7 GREEN. Проверяются title/price-before-gallery, один h1,
  одна цена, работодатель/условия/контакты и отсутствие лишней owner-кнопки.
- Инверсия условия показа payment-кнопки дала5 ожидаемых падений; после
  восстановления7/7, хеш исходника совпал. Дополнительная регрессия
  контраста seller sidebar прошла RED→GREEN.
- Старому function-extraction harness добавлены только bindings новых двух
  компонентов. Существующие assertions и quality guard не ослаблялись.
- Новый browser runner читает существующие синтетические fixtures и проверяет
  actual публичные страницы. Для объявления fixture выбирается через настоящий
  PostgresPublicListingStore: простого status=published недостаточно, поскольку
  запись может быть заблокирована. Ограничения публичности не обходятся.
  Кабинет проверяется отдельным изолированным transport fixture восьми
  состояний с проверками отсутствия Details и сохранения действий. Старый
  helper cabinet-card-browser-cases не менялся: его selector прямого child ul
  устарел после прежнего переноса списка в TwoRowCardViewport. Новый runner
  работает с actual region/карточками, не адаптирует тайно старый selector.
- В native1855/1855 нет fail/skipped; финальная сборка Next15.5.27 успешна.
- Финальный check:fast после сборки успешен (floor/types/lint); сохранено
  прежнее предупреждение checkout-prerequisites.test.cjs:30 targetType.
- Финальный Chromium runner полностью прошёл: все три actual public page,
  title→price→gallery, 320/768/1024/1440 без overflow и serious/critical axe,
  восемь owner-состояний, отсутствие Details, три payment/status-кнопки,
  клавиатурное открытие Actions и прежние edit/view/unpublish действия.
  Нет незапрошенных account mutations и pageerrors. Screenshot desktop/mobile
  просмотрены. Локальный стенд запущен, health200.
- Оставшийся контраст в hover-summary подтверждён axe (4.38 при требуемых4.5),
  исправлен и проверяется дополнительными assertions новых card-регрессий.

Это не полный аудит всех legacy UI и всех hover/disabled состояний: например,
старый отдельный ListingOwnerVisibilityButton не перерабатывался в этой задаче.

Не менялись демо-клиенты, выключенные в текущем primary-контуре; формат
применён к фактически используемым server-rendered публичным маршрутам.

Единственное изменение workflow: новый обязательный шаг `Run isolated PostgreSQL 18 integration gate` в существующем `validate`, перед production build/package/upload. Guard, types/lint/native, layout-проверки, audit, security/CodeQL, deploy dependencies, timeout20min и откат сохраняются. Дополнительных permissions, secrets, if/continue-on-error нет.

Шаг устанавливает Chromium с системными зависимостями по [официальной инструкции Playwright](https://playwright.dev/docs/ci), затем загружает только фиксированный digest PostgreSQL18.6 и последовательно исполняет13 существующих интеграционных наборов: базовые транзакции/TLS, bootstrap/minimal grants, Telegram, удаления, профессии, поиск, бронирования, финансовая сверка/удаление, разрешение возвратов, компенсационные cases, owner lifecycle, защита оплачиваемого отклика и отмена подготовки. Каждый создаёт собственный контейнер с синтетическими данными; штатная ручная БД, .env и production не используются. `--test-concurrency=1` ограничивает память и одновременные контейнеры.

Защита ветки GitHub отдельно не настраивается. На PR шаг также обязателен. Изменение workflow локальное; оно не запускает GitHub и не публикует сайт.

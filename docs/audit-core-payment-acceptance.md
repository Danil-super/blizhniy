## Сквозная приёмка на ручном стенде

Для объявления, вакансии и заказа: сохранённая форма с фото → открытие этой
же формы → подготовка оплаты → отмена до anchor → новая подготовка → переход
в симулятор → подтверждённое исполнение → reload → публичная200 → изменение
названия через форму без второй оплаты → актуальная публичная карточка.
Один оплаченный receipt и первоначальный срок сохраняются; отдельный отменённый
заказ остаётся в истории без anchor/receipt. Для вакансии и заказа дополнительно
снятие→404 и восстановление→200 без изменения оплаченного периода.

Неподтверждённый телефон допускает просмотр тарифа, но НЕ подготовку покупки:
PUT403 PHONE_REQUIRED, финансовая запись не остаётся. Некорректная сумма,
нероссийский телефон и HTML в описании отклоняются422 без создания карточек.
Проверяется отсутствие горизонтального переполнения на320/768/1440px.

Бесплатная анкета берёт имя из профиля и готова к отклику без покупки анкеты.
Отправка через «Оплатить и отправить» открывает оплату; до неё заказчик получает
404 при чтении отклика. После capture — доступный заказчику отклик с точным
исходным сообщением и единственной записью доставки. Внешних запросов браузера
и pageerror нет. Создание учётных записей/подтверждённого телефона здесь является
fixture; реальная регистрация/Telegram этим сценарием не проверяются.

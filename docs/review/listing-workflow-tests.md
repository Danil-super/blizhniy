Дополнительный редактор больше не закрывается отдельной кнопкой: проверки его
специфического закрытия заменены проверками единой формы и смены аккаунта.
При конфликте владелец явно видит серверную версию и выбирает **замену всей формой**,
а не прежнее слияние только дополнительных полей. Это соответствует сохранению
целого объявления из одной формы; тесты проверяют точную bigint revision и отсутствие
записи до явного решения. Низкоуровневые ownership/photo/CAS тесты старого API
сохранены отдельно, без удаления assertion или пропусков.

## Узкая правка guard

Предложения: [guard](listing-workflow-floor.patch), [его новые регрессии](listing-workflow-floor-tests.patch).
Полный diff четырёх браузерных файлов: [listing-workflow-tests.patch](listing-workflow-tests.patch).
Разрешение действует только для четырёх полных файлов с точным SHA256 «до» и «после».
Любое другое содержимое, ещё одна удалённая проверка, другой исходный файл или
посторонний путь снова блокируются. Запреты suppressions, skipped/deleted tests,
ослабления порогов и все CI steps не меняются. Прежние точные регистрации-policy
исключения остаются без расширения.

## Найденный и исправленный дефект

HTTP-приёмка обнаружила503 на расчёте стоимости. Изолированная тестовая web-роль
имела лишние для настоящего стенда `UPDATE(id)` на городах/профессиях, поэтому
не выявляла42501 при `SELECT ... FOR SHARE`.

Права web-роли не расширены. По существующему шаблону заказов web-проверка теперь
читает справочники без лишней блокировки; SQL0060 по-прежнему самостоятельно
блокирует и повторно проверяет их при записи условий и выполнении размещения.
Перед первым POST симулятора доверенная owner-транзакция также блокирует/проверяет
цель. После ожидания user-lock повторно читается уже созданный provider ID,
чтобы изменение справочника не ломало восстановление прежнего результата.

PG-fixture усилена: web-роль лишена UPDATE справочников. Добавлены проверки
изменения данных непосредственно перед POST и восстановления конкурентно
созданного платежа. SQL/схема/GRANT при исправлении не менялись.

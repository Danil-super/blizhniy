# Единое редактирование материалов — локально

Проверено 23.10.2026. Только собственный PostgreSQL-стенд, синтетические
аккаунты, локальные файлы и симулятор платежей. Production, права рабочей БД,
SSH, LIVE и реальные списания не менялись. Это не отчёт о завершении всего
переезда или допуск к production.

## Поведение

У карточки «Редактировать» открывает отдельную исходную форму выбранной
записи. «Подробнее» показывает сведения и статус без второго редактора.
После подтверждённого сохранения открывается список кабинета с обновлённой
карточкой. На странице редактирования не загружается список других записей.
Порядок оплаты и публикации этим изменением не меняется.

| Материал | Список | Редактирование |
|---|---|---|
| Вакансия | `/cabinet/vakansii` | `/rabota/vakansii/:id/edit` |
| Заказ | `/cabinet/zakazy` | `/rabota/zakazy/:id/edit` |
| Анкета специалиста | `/cabinet/specialist` | `/rabota/specialisty/anketa?draft=:id` |
| Заявка ярмарки | `/cabinet/fair-applications` | `/yarmarka-masterov/zayavka?draft=:id` |
| Рекламный текст | `/reklama/begushchaya-stroka?view=list` | `/reklama/begushchaya-stroka?draft=:id` |

Прямое открытие и reload читают сохранённую запись с проверкой владельца.
При временной недоступности сессии приватная форма скрыта и неинтерактивна,
но её несохранённый буфер сохраняется в памяти для того же владельца.
Подтверждённый выход или смена аккаунта сбрасывают owner-scoped редактор.
Переход по ссылке не запускает запись, оплату или публикацию; leave guard,
CAS и исходные обработчики сохранения/фото сохранены.

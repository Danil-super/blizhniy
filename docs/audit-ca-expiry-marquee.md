## F21 — загрузка доверенного CA

`readPostgresConfig` читает сертификат через один дескриптор: `O_NOFOLLOW | O_NONBLOCK`, `fstat`, обычный файл размером 1–65536 байт, ограниченное чтение до 65537 байт для обнаружения роста. Разрешён владелец root или текущий Unix-пользователь; запись для группы/остальных запрещена. Публичный сертификат может иметь права 0644, секретным ключом он не считается. Дескриптор закрывается при успешном чтении и ошибках; ошибка закрытия тоже нормализуется без повторного close.

`verify-full`, проверка CA и имени сервера, обязательный CA, запрет отключать TLS на удалённых адресах сохранены. Закрыт check/use разрыв последнего компонента пути, а не доказан сценарий удалённой атаки: HTTP-пользователь не выбирает CA path. Защита каталога и прав оператора по-прежнему обязательна. Перед будущим выпуском нужно проверить владельца/права CA для каждого сервисного пользователя; рабочие файлы этой работой не менялись.

Новый тест сначала воспроизвёл 13 отказов из 20; отдельное ревью дополнительно воспроизвело ошибку закрытия. После исправлений проходят 21 новая проверка: настоящий symlink, writable modes, FIFO без блокировки, каталог, пустой/слишком большой файл, точная граница, замена пути, рост после fstat, короткие чтения и освобождение дескриптора. Положительные fixtures теперь создают публичный CA с явным 0644 вместо зависимости от umask 0002. Assertions и права секретных ключей не ослаблялись. Собственный локальный CA также переведён с 0664 на 0644 через проверенный дескриптор; новая генерация стенда задаёт 0644 явно.

## F10 — эффективное окончание размещения

Общий SQL helper меняет только возвращаемый статус: `published` при `expires_at <= statement_timestamp()` становится `expired`. Используется в work/service snapshot, intent read, owner list и отдельной проекции карточек вакансий/заказов. Часы и исключительная граница окончания совпадают с SQL публичной выдачи. Приоритет выбранного исполнителя в карточке заказа сохранён. Неопубликованные состояния не меняются.

Модели ответа и права БД сохранены. Существующие `publishedAt`/`expiresAt` из private snapshot показаны в редакторах с пояснением, что редактирование не продлевает размещение. Публичный каталог, прямое чтение и private DTO проверены до/после границы; точное равенство и ±1 микросекунда проверены в одном SQL statement. Статус — проекция на момент серверного чтения, не фоновый исполнитель и не управление продлением. Обновление уже открытой страницы, новая покупка периода и прочий lifecycle остаются отдельными задачами.

Настоящий PG18.6 regression сначала дал 17 расхождений `published`/`expired`. Теперь проходят 35 проверок двух типов работы и трёх сервисных материалов. Они также проверяют отсутствие изменений status, оплаты, revision, формы и дат в БД и запрет runtime менять финансовые поля. В Chromium на собственном стенде проверены истёкшие вакансии, заказы и ярмарка: карточки, отсутствие публичной ссылки и оба времени в редакторе. Для этого создаются только отдельные синтетические аккаунт/публикации и операторская тестовая привязка телефона; общая политика телефона остаётся включённой. После допустимого перехода в публикацию оператор сдвигает только эти тестовые даты в прошлое, затем удаляет созданный аккаунт. Это проверка чтения, не проверка настоящего платежа.

## F19 — доступное управление рекламной строкой

Загрузка текста остаётся в серверном `HomeHero`. Небольшой client-компонент добавляет кнопку остановки/включения движения, связанную с текстом через `aria-controls`. Тексты приходят в исходном HTML и не дублируются для анимации/скринридера; автоматических live-объявлений нет.

При остановке все сообщения переходят в статичный переносимый текст, чтобы не замораживать пустую или обрезанную часть строки. Повторное включение начинает новый цикл. `prefers-reduced-motion: reduce` полностью отключает анимацию, убирает ненужный переключатель и показывает весь текст. Native-тесты проверяют серверную разметку и экранирование. Настоящий Chromium проверяет Enter, touch, размер кнопки 44×44, возобновление, переключение системной настройки и читаемость при 320 px.

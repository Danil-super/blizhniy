# Диагностика локального запуска — 17.11.2026

После установки62 один запуск ранее остановился до готовности. Старый launcher
сохранил только общую ошибку; установить причину задним числом нельзя.
Диагностический пробел исправлен, исходный сбой пока не признан устранённым.

`local-primary.mjs` теперь пишет отдельные JSON-события для fixture, build,
configuration, refunds, user-access, proxy, application, expiry и общей services.
У запуска есть runId и PID; у стадии — started/completed/failed и длительность.
Значения конфигурации, пути, содержимое исключений и возвращённых ресурсов
не сериализуются. Отказ записи журнала не теряет полученный ресурс и не заменяет
исходную ошибку. Диагностика не меняет тайм-ауты, права, отмену или очистку служб.

ready приложения: для этого после каждого запуска выполнена отдельная HTTPS-проверка.

нагрузки host. Сбой не воспроизведён; нагрузка не объявляется доказанной причиной.
Если он повторится, последняя started-стадия и failed-событие локализуют отказ.

# Кабинет, заблокированные объявления и вакансии — локально 21.10.2026

Область: только https://127.0.0.1:3045, синтетические данные и симулятор оплаты.
Нет push, deploy, изменений рабочей БД или реальных списаний.

## Поведение

- Список объявлений ограничен 65vh, прокручивается мышью и клавиатурой.
- Заблокированная карточка предлагает редактирование исходной формы и удаление
  из кабинета. Редактирование не снимает блокировку; удаление не стирает исходник,
  причину, оплату и админскую историю. Требуется подтверждение пользователя.
- Одобренная 0029 применена только к проверенному локальному контейнеру:
  runtime SELECT новой таблицы и INSERT трёх полей, без UPDATE/DELETE.
  Подробности: [контракт удаления](listing-owner-removal-local.md).
- Профессия выбирается в ограниченном списке с поиском, Arrow/Enter/Escape,
  видимой ошибкой неизвестного значения и стандартной проверкой формы.
- От 1024px оплата, график и формат работы расположены в одном ряду;
  на меньших экранах — по вертикали. Сохранённые нестандартные значения
  графика и формата не теряются при повторном открытии.
- Вакансии и заказы в кабинете отображаются равными карточками: фото 4:3,
  сумма, работодатель/профессия, город, график, статус и действия.
- Постоянной кнопки «Обновить список» нет; при ошибке появляется явный retry.
  Смена фокуса не перезагружает список и не стирает несохранённый редактор.

# Единое редактирование фото и даты заказа — локально

23.10.2026. Изолированный стенд https://127.0.0.1:3045/__local.
Production, SSH, рабочая БД, схема/ACL, LIVE и реальные списания не менялись.

## Поведение

- У карточек заказов в кабинете нет «Подробнее»: редактор открывает
  «Редактировать», публичную страницу опубликованного заказа — «Посмотреть».
- Объявления, вакансии, заказы, анкеты и ярмарка используют один блок
  сохранённых и новых фото: общий счётчик/лимит, добавление, удаление из формы,
  возврат последнего удалённого, кадрирование и выбор обложки.
  Недоступное превью не удаляет сохранённый media ID; есть явный retry.
- Кадрирование создаёт новый файл вместо изменения исходного. Смешанный
  порядок saved/new фиксируется до загрузки файлов, сохраняется вместе с
  формой и не меняется при повторе после неизвестного результата записи.
  Сам выбор/кадрирование не записывает публикацию до сохранения формы.
- Публичный заказ читает актуальную сохранённую версию. «Размещено» сохраняет
  исходную дату, «Обновлено» отражает последующее редактирование. Техническая
  запись capture не выдаётся за редактирование. Даты показаны с явными
  подписями, временем Москвы и семантическими time-элементами.
- Действующие owner/CAS/readback, неизменяемые платежные документы, срок и
  refund gate сохранены. Дополнительных прав/таблиц не потребовалось.
- Район пока сохранён необязательным: для заказа достаточно города;
  удаление поля и сохранённых значений этим изменением не выполнялось.

# Исправления формы и фотографий — 17.11.2026

Четыре замечания владельца исправлены локально. Production, push, SQL/роли,
реальные платежи и настройки двух российских серверов не менялись.

## Ошибка загрузки блокировала исправление

Независимый browser regression воспроизвёл исходный отказ: после422 INVALID_INPUT
кнопки кадра/удаления оставались disabled. `PrimaryListingFormButton` включал
active для зафиксированного снимка формы, но media-ошибка не завершала этот режим.
Сброс busy сам по себе не снимал блокировку соседних полей.

Теперь явный отказ фото/квоты до записи формы запускает чтение уже созданного
черновика. Разблокировка происходит только при прежней ревизии. Исправление
продолжает тот же ID/revision; новый пустой черновик не создаётся. Неопределённая
запись/конфликт версии не превращаются в автоматическое разрешение перезаписи.
При отказе чтения остаётся явная проверка, поля не разблокируются вслепую.

В заказах/вакансиях фото загружаются до создания публикации; подтверждённый отказ
также освобождает поля. Уже успешно загруженные файлы сохраняются в прежнем
in-memory cache: ошибка второго файла не вызывает повторную загрузку первого.
Кэш живёт только в текущем owner-scoped компоненте.

## Подготовка фотографий

Оба общих загрузчика используют один browser helper, без новых зависимостей
и внешних сервисов. JPEG/PNG/WebP до50МБ уменьшаются с сохранением пропорций
до2048px по длинной стороне и кодируются в WebP до2МБ. До трёх ограниченных
попыток качества; файлы обрабатываются последовательно, bitmap/canvas освобождаются.
EXIF-поворот камеры применяется до кодирования; исходное имя остаётся в интерфейсе.
Исходники свыше64MP отклоняются с понятным сообщением. Это не обещание поддержки
произвольного формата/размера: HEIC и повреждённые файлы не принимаются.

GIF до8МБ передаётся серверу без превращения анимации в первый кадр;
APNG/animated WebP также не маскируются клиентом под статичную картинку.
Строгие проверки формата/статичности, пикселей, WebP и квоты на сервере сохранены.
Во время подготовки нельзя сохранить неполный список файлов; форма сообщает
о необходимости дождаться обработки. Legacy editor без подготовки сохраняет
свою прежнюю честную подсказку10МБ; текущие формы показывают автоматическое сжатие.

## Профессии и стоимость

Из видимых вариантов профессии убран технический slug; русская категория
для различения одинаковых названий и привязка по UUID сохранены. Владелец
отдельно одобрил [точную замену теста и одну SHA-пару guard](review/photo-profession-test.md).
Применён именно этот patch; остальные запреты guard не менялись.

Стоимость принимает цифры и одну запятую/точку, до двух знаков копеек.
Недопустимая вставка отклоняется целиком, `1e3` не превращается в13.
Внутри поля только числовой пример `5000`; пояснение о пустом значении вынесено
под поле. Пустое значение остаётся допустимым, нулевая/отрицательная сумма — нет.
Серверный денежный parser и сохранение точных десятичных рублей не менялись.

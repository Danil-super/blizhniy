# Точечное обновление браузерного ожидания роли

База: 8084e8d35edfff7bec530956db0d9e9c78049afd.

Настоящий PostgreSQL/browser runner воспроизвёл тайм-аут ожидания старой подписи «Администратор · права проверяет сервер». Текущий LocalAccountForm.tsx отображает «Администратор». Смена роли в БД и её повторная проверка в UI остаются обязательными.

В audit-role-label.patch предложены только две замены селектора на точный видимый текст «Администратор»: ожидание после назначения роли и отсутствие после блокировки. Все запросы, действия, assertions и количества проверок сохраняются; skip, retries, timeout и guard не меняются.

Это предложенный diff: владелец одобрил и точечная замена исходного теста применена 29.10.2026. Изменение guard требует отдельного review владельца по CONSTRAINTS.md, раздел «Действующие механизмы». Полный PG/browser runner не объявляется зелёным до согласования и повторного выполнения.

## Точная пара в защите тестов

Guard распознал замену селектора как assertion-removed. В audit-role-label-floor.patch предложено добавить одну точную пару before/after для одного файла в существующий механизм. Обе строки должны встречаться ровно один раз в diff; остальные удаления остаются запрещены. Ни regex правил, ни пороги, ни workflows не меняются. Этот дополнительный patch одобрен владельцем и применён 29.10.2026. Новый quality-floor-role-label.test.mjs проверяет точность пары и отклонение несогласованных вариантов/других файлов.

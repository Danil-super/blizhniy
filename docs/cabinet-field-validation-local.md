## Модель угроз

Недоверенные значения: DOM/FormData/HTTP JSON, включая скрытые поля, ссылки и IDs.
Активы: данные пользователей, приватные контакты, владение материалами, финансовое состояние.
Сервер не доверяет браузерным маскам, имени владельца или данным профиля в запросе.
SQL — только параметры `$n`; HTML — текст с автоматическим экранированием React.
Нельзя подменять эти границы регулярным выражением или запретом SQL-слов.
Обычная пунктуация, апострофы, цифры в описаниях и математические сравнения допустимы;
HTML-разметка, управляющие C0/C1 и bidi-переопределения — нет.
Пароли не ограничиваются правилами человеческого имени/описания.

## Правила и охват

| Поля | Проверки |
| --- | --- |
| Имя профиля / контактное лицо / частный работодатель | Unicode-буквы, пробел, дефис, апостроф, точка; без цифр/разметки; ограниченная длина |
| Заголовки, описание, навыки, опыт, условия, обязанности, комментарии, сообщение отклика | Строка, предел длины; без HTML и C0/C1/bidi-переопределений; обычная пунктуация/цифры/апострофы допустимы |
| Стоимость, зарплата, бюджет, цены аренды | Неотрицательная десятичная сумма до 9 999 999 999,99, не более двух дробных знаков; без экспоненты/NaN/Infinity/букв; готовность к оплате проверяется отдельно |
| Количество гостей/ночей | Целое число в пределах схемы; бронирование дополнительно проверяет доступность и предел 1000 гостей |
| Телефон | Только телефонная пунктуация и цифры, 10 цифр или 11 с 7/8; SMS не включён |
| Email и мессенджер | Формат адреса / допустимый handle или HTTP(S)-ссылка; предел длины; без HTML/контролов/credentials в URL |
| Сайт, видео ярмарки, рекламная ссылка | Только HTTP(S), hostname, без логина/пароля, пробелов/контролов и разметки; сервер эти URL не загружает |
| ИНН, ОГРН/ОГРНИП | Только цифры и соответствующая длина; прежние контрольные суммы и тип работодателя перед оплатой сохранены |
| Город, профессия, категория | Существующие справочники и серверное разрешение ссылок; профессия анкеты — общий поисковый combobox |
| Координаты, даты, время, согласия, файлы и IDs | Прежние типы, диапазоны, календарная проверка, владение и размер файлов сохранены; цены аренды дополнительно ограничены копейками |
| Email для входа / пароль / системные IDs | Не превращены в редактируемые данные профиля; правила обычного текста не применяются к паролям/токенам |

Браузерная проверка не подменяет серверную: прямые HTTP-запросы с плохими
значениями профиля получают 422. Инъекционные строки в текстовом описании не
становятся SQL: существующие хранилища передают значения параметрами `$n`.
Это целевой разбор полей кабинета, не новый полный security-аудит всего проекта.

## Анкета и совместимость

Production composition исходников явно включает `specialistProfileIdentity:true`
для приватного сохранения и публичного чтения/медиа; рабочее окружение не обновлялось.
Совместимый низкоуровневый store без опции оставляет старый формат для прежних
интеграционных fixtures; HTTP runtime никогда не берёт эту опцию из запроса.

Сервер читает имя только из `app.cabinet_profiles` собственного аккаунта внутри
авторизованной транзакции. Сохранение анкеты очищает её старые district/video/photoIds;
сами media_objects и файлы массово не удаляются. Публичный DTO берёт только имя
и аватар опубликованной анкеты из профиля, не экспортирует контакты/настройки и
не показывает прежнее портфолио/видео/район. Старый public-photo endpoint не выдаёт
портфолио профильной анкеты. Отсутствие аватара — пустое фото, не чужая картинка.

Отдельные страницы service-форм теперь имеют профильный provider. Форма ждёт
первые defaults профиля, но не перемонтируется при временной перепроверке сессии.
Если имя в профиле изменилось между открытием формы и сохранением, readback
сравнивает все редактируемые поля, не считает серверное имя потерей данных и
не повторяет неизвестную запись автоматически.

В ярмарке сохранён собственный редактор фото/видео и название; прежний район
сохраняется скрытым полем, не удаляется молча. В других формах фотографии сохранены.
Модерация/оплата анкеты и остальных service-разделов этим заданием не менялись.
